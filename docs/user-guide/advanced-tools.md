# Advanced Tools

Save-wide tools that do not belong to a single character.

## Save Information

Shows the platform, SteamID, number of active characters and file size of the loaded save.

## Tools

- **Validate Save File** - checks the save structure and reports problems
- **Recalculate All Checksums** - rewrites the checksums of every slot and USER_DATA_10
- **Refresh Information** - reloads the save information panel

## Game Settings

**Game Settings...** opens the in-game options stored in the save. They are shared by all characters in the file.
A backup is created before the change is written.

- Sound: brightness, master, music, sound effect and voice volume, sound type
- Camera: speed, X and Y axis, auto wall recovery, reset Y axis, auto rotation, cinematic effects
- Controls: vibration, auto lock-on, manual attack aim, auto-target
- Display: blood, subtitles, HUD, HDR values, ray tracing, mark new items, show recent tabs, show tutorials
- Network: cross-region play, voice chat, display player names, send summon sign
